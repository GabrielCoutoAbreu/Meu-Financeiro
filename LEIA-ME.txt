MEU FINANCEIRO v1.3.0 — PRIMEIRA INTEGRAÇÃO OPEN FINANCE / PLUGGY

ALTERAÇÕES
- Nova área Open Finance na tela Contas e cartões.
- Botão Conectar banco.
- O aplicativo solicita um Connect Token à Edge Function pluggy-connect-token.
- Abre o Pluggy Connect oficial em português.
- Exibe apenas conectores do Brasil e bancos pessoais.
- Ao concluir a conexão, salva o itemId na tabela public.pluggy_items do Supabase.
- A lista de bancos conectados é carregada por usuário e protegida pelas políticas RLS.
- Esta versão ainda NÃO importa saldos e transações automaticamente. Isso será a próxima etapa.

ANTES DE USAR
No SQL Editor do Supabase execute uma vez:

grant usage, select on sequence public.pluggy_items_id_seq to authenticated;

Isso permite que o ID automático da tabela pluggy_items seja gerado nas inserções feitas pelo usuário autenticado.

COMO ATUALIZAR NO GITHUB
1. Abra o repositório Meu-Financeiro.
2. Use Add file > Upload files.
3. Envie os arquivos desta pasta para a raiz.
4. Faça Commit changes na branch main.
5. Aguarde o GitHub Pages publicar.
6. No iPhone, feche completamente o app e abra de novo.

TESTE
1. Entre em Contas e cartões.
2. Toque em Conectar banco.
3. Escolha uma instituição e conclua o consentimento.
4. Ao final, a instituição deverá aparecer em Bancos conectados.

SEGURANÇA
- CLIENT_ID e CLIENT_SECRET da Pluggy continuam somente nos Secrets das Edge Functions.
- O navegador recebe apenas Connect Token temporário.
- O itemId fica associado ao usuário autenticado no Supabase.
